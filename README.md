# Portfólio — Luiz Gabriel de Souza

Site acadêmico de Ensino Médio Técnico em Internet das Coisas (IoT), criado em HTML, CSS e JavaScript, sem bibliotecas e sem internet obrigatória.

## Como visualizar
Abra `index.html` no navegador. Para testar publicação, use a raiz do repositório GitHub Pages.

## Páginas
- `index.html`: início e apresentação com a foto fornecida.
- `areas-do-saber.html`: quatro áreas curriculares e conexões com tecnologia.
- `formacao-tecnica.html`: descrição detalhada do projeto Esteira Inteligente.
- `curriculo.html`: competências, formação e objetivo.
- `memorias.html`: foto pessoal e locais de evidências.
- `jornada.html`: linha do tempo ilustrativa; revisar os anos e projetos individuais.
- `contato.html`: WhatsApp, Instagram, e-mail e cidade.

## Organização técnica
`css/style.css` centraliza cores, componentes, Grid, Flexbox e media queries. `js/main.js` abre o menu responsivo e atualiza `aria-expanded` para acessibilidade. `assets/imagens` contém a fotografia; `assets/videos` e `assets/documentos` estão preparadas para registros reais.

A placa de veículo visível na fotografia original foi desfocada na versão publicada por privacidade.
